
# Madrid Audio Guide AI

Audioguía inteligente de Madrid con GPS e inteligencia artificial.

## Funciones

- Mapa interactivo de Madrid.
- Avisos geolocalizados al acercarse a monumentos.
- Audioguías reproducibles bajo demanda.
- Asistente turístico con inteligencia artificial.
- Soporte previsto para seis idiomas:
  español, inglés, francés, alemán, italiano y portugués.

## Tecnologías

- React y TypeScript
- Leaflet y OpenStreetMap
- Node.js y Express
- API de OpenAI
